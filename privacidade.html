Política de Privacidade

Controle Financeiro e Controle Financeiro Bot · atualizada em 26/10/2026

O que é

O Controle Financeiro é um painel de uso pessoal e familiar para registrar trabalhos, entradas e gastos. O Controle Financeiro Bot recebe mensagens de WhatsApp enviadas pelos próprios donos do painel para anotar gastos.

Quais dados coletamos

  • Conta Google usada para entrar no painel (nome e e-mail), apenas para liberar o acesso.
  • Mensagens de texto e áudios enviados ao bot, usados somente para identificar o valor, a descrição e a data do gasto.
  • Número de WhatsApp de quem envia, para confirmar que a pessoa está autorizada a usar o bot.

Como usamos e guardamos

Os gastos ficam salvos no banco de dados do painel (Google Firebase), acessível apenas pelas contas autorizadas. Os áudios são convertidos em texto e não são guardados. Não vendemos, não compartilhamos e não usamos esses dados para publicidade.

Serviços de terceiros

Usamos a API do WhatsApp Business (Meta) para receber e responder mensagens, o Cloudflare Workers para processá-las e o Google Firebase para armazenar os dados. Cada serviço segue sua própria política de privacidade.

Exclusão de dados

Qualquer lançamento pode ser apagado pelo próprio painel ou enviando "desfazer" ao bot. Para excluir todos os dados, peça pelo próprio WhatsApp do bot.
