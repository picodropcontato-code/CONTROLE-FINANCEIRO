Como criar o Firebase grátis? (Passo a passo rápido)
  1. Acesse console.firebase.google.com com sua conta Google.
  2. Clique em "Criar um projeto" (ou "Adicionar projeto") e dê um nome (ex.: Trabalhos). Pode desativar o Google Analytics.
  3. No menu lateral esquerdo, vá em Criação (Build) → Realtime Database → clique em Criar banco de dados e selecione "Iniciar no modo de teste" (permite leitura e escrita).
  4. No menu lateral, vá em Authentication → clique em Primeiros passos → aba Sign-in method → ative o provedor Anônimo e salve.
  5. Clique na engrenagem ⚙️ (Configurações do projeto no topo) → role até "Seus aplicativos" → ícone Web (</>) → registre o app e copie o bloco const firebaseConfig = { ... };.
  6. Cole o texto copiado nas opções avançadas e confirme.
